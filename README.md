## What it does

A qualified collector still cannot complete a DOT test alone. A specimen needs an
HHS-certified laboratory to analyse it and a Medical Review Officer to verify the result
before it means anything. Both are accounts you set up in advance, not things you arrange
per test.

This page lists the providers TestRight features for that setup, along with supplies and
software.
